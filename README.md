# Hi, I'm Dylan

## Featured project: AU Core Gateway

Converts pathology lab HL7 v2 messages into AU Core FHIR, with every record checked by the official HL7 validator. All 1,156 synthetic patients and 384,727 test results pass, and all 250 deliberately planted errors are caught at the exact field, with no false alarms.

[Live dashboard](https://dylandchand.github.io/au-core-gateway/) · [Project write-up](https://github.com/dylandchand/au-core-gateway/blob/main/docs/WRITEUP.md) · [Code](https://github.com/dylandchand/au-core-gateway)
